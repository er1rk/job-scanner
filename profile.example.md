# Example candidate profile

The real profile is stored in the `CANDIDATE_PROFILE` GitHub secret and is never committed.
Write yours in the same style: short factual bullet points, including what you do NOT have,
so the model doesn't assume skills you lack.

- X years as a [role] at [company type]: [2–3 main responsibilities]
- Tools: [e.g. advanced Excel, Power BI]; [tools known only at a basic level]
- Education: [degree, status, expected graduation]
- Languages: [language – level]
- Not experienced with: [e.g. SAP, accounting]
- Target: [locations / remote], [seniority], [roles to avoid]
